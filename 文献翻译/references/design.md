# 首版规划与验收口径

## v3 的落实

**主方向是可回查的段落级双语翻译。** 原文清单先于译稿建立。长文按段分批，源句与译句支持一对多和多对一。逐次术语注册、数字归属和保护项检查服务于同一份对齐结果。问答、提取和核验已有译稿只处理题目需要的证据范围。

- **覆盖分母。** 有分页的输入始终报告应覆盖页和提取到文字的页。正文、题注、表格和公式另按实际可识别单元记录。题目要求但提取结果缺失的图片或字段在复审核验中单列。
- **关联强度。** 公式、引用、数值与术语先绑定源句和单元。机器归属仅判定显式组标、简单一值陈述、明确的对应列表及表格单元位置。相同数字集合、相同段数或译文顺滑均不足以认定归属正确。组别、条件、因果和限定进入语义复审。
- **原生 PDF 与 OCR。** 首版采用本地已验证的 `pypdf==6.21.4` 提取文字层与物理页，会标记识别到的阅读顺序风险。扫描 OCR 和复杂版面恢复由可用的宿主工具提供，首版核心验收只要求正确阻断或部分交付。视觉转写变更附原页证据。
- **断点与保留。** 锁定后的词表实际写入逐次注册表。段落响应和复审绑定实际输入。源材料无法辨认、图片无可靠读数、术语歧义以及批准的源文保留和逐处例外均有记录。应译内容不可读仍是覆盖缺口。局部漏译和错误令牌要按源段返修。

## 最小自查

| 用例 | 验收证据 |
|---|---|
| 漏一段 | `missing_unit` 含具体单元 ID 与页码，其余段继续交付 |
| 同一术语三次出现，中间一次错译 | `term_occurrence_missing` 精确到令牌和源句，另外两次状态可核对 |
| A、B 数值对调 | `numeric_binding_mismatch` 给源值与原组、译文所在组。完全保留令牌仍出现错绑，正确重排通过 |

还自查了跨段错误令牌、合译和拆译、词表增量、目标变更导致复审到期、范围缺页及 PDF 无文字层。合成示例的译文与复审标为预置演示资料。

## 平台对照

平台使用组织方固定的三个案例和白板。以相同案例输入、任务范围、术语口径及可比运行条件评估。将两边输出映射到事先从原文确定的应评单元、术语出现位置和事实点。沿用独立原文分母，范围内缺页、漏内容及无法定位项单列。写明覆盖范围和未知项。

| 评分项 | 对照证据 |
|---|---|
| 实际效果 | 要求单元的合格覆盖、引用与公式等要素、数据和逻辑关系正确性、段句定位 |
| 使用增益 | 对固定白板比较覆盖、术语执行和事实复核。运行时间使用从读取输入到可复核产出的实际记录，区分首次和续跑 |
| 创新增益 | 逐段组装、逐次术语和数值归属检查的可复现缺陷定位，以及允许合法重排的对照 |
| 可靠体验 | 实际首次调用、局部返修、重复运行、缺材料和无文字层时的状态与可接管位置 |
| 生态贡献 | 可加载入口、相对路径的脚本依赖、结构契约、可复现最小调用和版本资料 |

术语表执行按应执行的源出现次数统计，合法例外和待判项单列。术语专业正确性、指代、因果、限定和引用支撑需要在固定口径下对照原文审阅。脚本报告自己的机械结果。正式增益、用时对比、真实案例通过状态由平台测出。
