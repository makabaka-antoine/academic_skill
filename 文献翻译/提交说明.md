## 提交范围

本目录是一个完整、独立的 Skill。`scripts/`、`references/` 和 `requirements-pdf.txt` 是运行资源；`examples/minimal/` 是明确标注的合成最小示例；`tests/` 是合成回归测试。未加入其他参考 Skill、组织方正式案例、白板、预制正式答案或虚构评测结果。

Harbor 评测时，将本目录内容作为提交根目录，使 `SKILL.md` 位于 `/app/submission/SKILL.md`。平台安装后通常从 `/skills/weekly-skill/SKILL.md` 加载。运行时读取 `/input/case.json`、`/input/task.md` 和实际科研材料，中间文件置于 `/app/work`，最终结果置于 `/app/output`。最终 `result.json` 必须保留 `case_id`、题目原 `output_contract` 的全部字段、真实状态、来源、不确定性和变更记录。

## 本地使用与自查

需要 Python 3.10 或更高版本。处理原生 PDF 前安装可选依赖：

```text
python -m pip install -r requirements-pdf.txt
```

从本目录运行最小示例（请换用一个不存在或为空的输出目录）：

```text
python -B examples/minimal/run_example.py --run-dir demo-run
```

运行合成回归测试：

```text
python -B -m unittest discover -s tests -v
```

最小示例中的译文及 `fixture_review` 均为演示数据，不是组织方正式案例结果。真实任务由 Agent 读取当次请求并完成翻译。完整输入输出、术语表、令牌、复审及异常状态约定见 `README.md` 和 `references/contracts.md`。
