# Source formats and editable files

- **UTF-8 text and Markdown.** Read the complete editable passages. Preserve code, fenced blocks, YAML, link destinations, citations, table structure, headings and ordering unless a requested format change affects them. Repair a genuine textual problem within authorized captions or headings. For garbled text, identify the encoding from a BOM or other evidence, retain the original, and compare a decoded preview. Never replace unreadable characters in research content with guessed ones.
- **LaTeX fragments and projects.** Identify the actual entry file and included sources when a full project is requested. Preserve math mode, macros, labels, bibliography keys, source comments, cross-references and preamble. A caption or `\emph{}` argument can contain editable prose. Inspect the changed source with references in place. If a build is required and the declared compiler is available, use the project's engine and bibliographic backend, inspect its log and open the resulting pages. For a fragment, deliver editable TeX and mark build status only when relevant.
- **PDF inputs.** Read the actual PDF. Use `pdftotext -layout` or the declared text extraction tool. Compare critical passages to page images when extraction may confuse columns, rows, hyphenation, superscripts or signs. Use local OCR for scanned pages and verify ambiguous glyphs visually. Keep a page plus excerpt or section/paragraph locator for each adopted quote, value or finding. Extract into the work area. A PDF label or suggested abstract is insufficient evidence of the body.
- **Editable Office outputs.** Use the supplied template and a declared native or local writer. For an existing document, preserve paragraph/run styling, fields, equations, comments and revisions as required. Author a new document when the case calls for one. A request for real tracked changes needs actual revision elements, not colored text. Export an actual PDF or PNG preview using the available Office renderer. Open the preview, inspect page breaks, math, tables, glyphs and change visibility, and ensure it matches the final editable file. Missing rendering or unverifiable markup is an execution issue. Keep a useful editable candidate and make the remaining check explicit.
- **Long or mixed inputs.** Batch by section or paragraph boundaries and preserve original order and the exact text of skipped units. Carry confirmed terms, definitions, protected facts and open items across batches. Recheck the assembled artifact. Keep source and candidate copies distinct. Use a narrow fallback on unreadable, conflicting or noneditable items and finish all unaffected units.
