# 学术语言润色

`academic-language-polish` 2.0.0 面向科研材料起草、分节润色、校对和中英对照写作。它把要求、出处、改动和最终文件绑定到能复查的位置。

公开作品地址：https://github.com/makabaka-antoine/academic_skill/tree/main/学术润色

## 安装与使用

1. 在支持 Agent Skills 的环境，将本目录作为 Skill 加载。保留 `SKILL.md` 与同级 `references/`、`scripts/`、`assets/`、`examples/` 的相对位置。Harbor 将这些文件安装到它的 Skill 目录。
2. 给出可编辑的草稿或原始材料，指明目标文本、语言、用途和期望格式。有已确认术语或格式规则时一并提供。可显式调用 `$academic-language-polish`，也可在聊天中直接提出“润色下面的 Results，保留限定语、数字和引用”。校对模式返回问题和定位，编辑模式返回可编辑的完整请求范围和逐句修改记录。
3. Python 3.10+ 提供材料清点、句级复演与交付核验。在普通聊天中也可沿用同一保真标准。PDF 文本首选运行环境的 `pdftotext`，也可用已安装的 `pypdf`。OCR、Office 渲染与 LaTeX 编译取决于宿主声明的实际工具。缺少工具或材料时交付可用部分及具体缺项。
4. Harbor 安装后按 [运行指引](references/harbor.md) 读取当次 `case.json` 和原始材料。`case_io.py` 捕获可复查的来源，`edit_audit.py` 复演同格式改动，`delivery_gate.py` 核对覆盖范围、出处、比较关系、改动和实际产物后写入 `/app/output/result.json`。

可先阅读 [最小调用示例](examples/minimal.md)。[术语表样例](assets/glossary.example.tsv) 和 [风格输入样例](assets/style.example.json) 是用户可替换的示例。风格 JSON 由 Agent 读入，脚本参数只读取 TSV 术语表。

## 方法与验收

| 方面 | 可核验产物 |
|---|---|
| 完整性 | 原请求的可编辑范围完整返回。逐句改动可在源文件和改稿中分别定位。 |
| 正确性 | 关键对照的每个数量与对应实体落在同一短证据片段，脚本核对原稿及成品中的实际位置。比较方向、因果、否定和限定另行阅读。 |
| 可核验性 | 修改 ID、来源位置、原句、改句、分类和理由。材料缺失、判断待定、执行失败有明确影响范围。 |
| 效率 | 一次捕获来源，批量复演改动，合稿后集中查覆盖和术语。评价时记录人工返修条目、使用轮次和待解决项。 |
| 增益与创新 | 用同稿、同术语表、同规则和同一评分口径比较。分开检查语言、保真、覆盖和可回溯性。复跑示例可验证脚本是否拦截数值替换和歧义定位。 |

通用语法工具适合标记句子问题，翻译工具适合提供目标语候选，人工编辑负责学科语义和修改取舍。这个 Skill 把候选和原稿版本、实际改动及保护项绑定，提供按句复核的材料。实际效益需要同条件对比。发布维护时记录版本，重跑示例与反例。包内规则、示例与代码为本提交原创实现。所参考的学术润色 Skill 与知识包用来识别失效方式，运行无需读取这些资料。

[审计命令与局限](references/audit.md) 说明字段、退出码和覆盖范围。投稿规范、引用是否支持原句、作者语义和渲染效果以实际证据核查为准。

## 提交目录与公开链接

本目录就是提交根目录，入口为根路径的 `SKILL.md`。提交时保留 `references/`、`scripts/`、`assets/` 和 `examples/` 的相对位置，不加入本地 work、output、缓存或其他赛题材料。具体范围与验收记录见 [提交说明](提交说明.md)。

根目录 `GITHUB_URL.txt` 第一行是本作品的公开目录，第二行是相对本提交根目录的 `SKILL.md`。远程公开版本必须与本次提交版本一致；同步后使用未登录 GitHub 的浏览器窗口打开链接，确认无需登录即可找到 `SKILL.md` 和全部必要资源。
