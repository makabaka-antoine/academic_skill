## 本地使用与自查

核心文本流程需要 Python 3.10 或以上，使用标准库。PDF 文本首选运行环境的 `pdftotext`，也可用已安装的 `pypdf`；OCR、Office 渲染、Pandoc 和 LaTeX 编译取决于宿主声明的实际工具。缺少工具或材料时交付可用部分并记录具体缺项，不把失败路径写成成功生成。

最小示例及原句—改句对照见 `examples/minimal.md`。保存示例正文后，可从本目录运行：

```text
python scripts/edit_audit.py check examples/source.md example-revised.md --glossary assets/glossary.example.tsv --language en
```

完整 Harbor 流程见 `references/harbor.md`。`case_io.py` 负责来源清点，`edit_audit.py` 负责同格式精确修改，`delivery_gate.py` 核对范围、出处、数值归属、修改重放和实际产物，`render_delivery.py` 仅在声明工具可用时生成 DOCX/PDF，且仍要求实际视觉复核。
